DIAPOSITIVA 5 - ¿POR QUÉ METABASE?
Título: Justificación Tecnológica

Comparación:
| Criterio | Metabase | Alternativas |
|----------|----------|--------------|
| Costo | $0 (open source) | Power BI: $10/usuario/mes |
| Tiempo implementación | 5 horas | Desarrollo custom: 20+ horas |
| Mantenimiento | Actualizaciones automáticas | Mantener código propio |
| Drill Down/Roll Up | Funcionalidad nativa | Programar desde cero |
| Curva aprendizaje | Interfaz visual sin código | Aprender librerías de gráficos |

DIAPOSITIVA 6 - MODELO ESTRELLA Y ANÁLISIS MULTIDIMENSIONAL
Título: Arquitectura de Datos BI

MODELO ESTRELLA (Star Schema):
- Tabla de Hechos: Mantenimientos (métricas)
- Dimensiones: Tiempo, Cliente, Vehículo, Mecánico, TipoServicio

FUNCIONALIDAD DRILL DOWN:
Ejemplo práctico:
Vista Anual → Click → Mensual → Click → Diaria → Click → Servicio Individual

Jerarquías implementadas:
- Temporal: Año → Trimestre → Mes → Semana → Día
- Servicio: Categoría → Tipo → Subtipo → Individual
- Organizacional: Todos → Especialidad → Mecánico

DIAPOSITIVA 9 - PLAN DE IMPLEMENTACIÓN
Título: Cronograma y Tecnología Docker

¿POR QUÉ DOCKER?
Con Docker (simplificado):
```
docker run -d -p 3001:3000 metabase/metabase
```
⏱️ Tiempo: 2 minutos

Ventajas: Portabilidad, aislamiento, fácil instalación, reproducibilidad

CRONOGRAMA - Tiempo total: 5 horas
Semana 1:
- Instalar Docker + Metabase (45 min)
- Conectar a PostgreSQL (20 min)

Semana 2-3:
- Crear 4 dashboards (2 horas)
- Configurar Drill Down/Roll Up (1 hora)

Semana 4:
- Pruebas, ajustes y capacitación (1.5 horas)
