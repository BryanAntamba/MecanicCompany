💼 ¿QUÉ VENDEMOS?

• Carrocería y pintura

🎯 ¿QUIÉNES SON NUESTROS CLIENTES?

• Propietarios de vehículos particulares
• Pequeñas flotas vehiculares
• Clientes que valoran:
  ✓ Profesionalidad certificada
  ✓ Transparencia en costos
  ✓ Comodidad digital
  ✓ Trazabilidad completa

🔄 ¿CÓMO SE REALIZA LA VENTA?

1. Cliente solicita servicio vía app móvil
2. Sistema registra automáticamente (estado: Pendiente)
3. Administrador asigna mecánico óptimo
4. Mecánico ejecuta servicio (estado: En Proceso)
5. Sistema genera reporte automático (estado: Completado)
6. Cliente recibe documentación vía email

💰 GESTIÓN FINANCIERA

• Registro automático de costos:
  - Mano de obra
  - Repuestos utilizados
• Cálculo de márgenes en tiempo real
• Análisis de rentabilidad por tipo de servicio
• Reportes financieros para contabilidad

📦 CONTROL DE REPUESTOS

• Registro de consumo por servicio
• Identificación de repuestos de alta rotación
• Optimización de negociaciones con proveedores

DIAPOSITIVA 5 - DIAGRAMA DEL PROCESO (Parte 1) (PRESENTADOR 3)
═══════════════════════════════════════════════════════════════════

TÍTULO:
Proceso Principal de Servicio (Fases 1-3)

CONTENIDO:

FASE 1: SOLICITUD DEL CLIENTE ✍️

CLIENTE:
• Accede a app móvil MecanicCompany
• Completa formulario con:
  - Datos del vehículo (marca, modelo, año, placa, km)
  - Tipo de servicio requerido
  - Descripción del problema
  - Fecha y hora preferida

SISTEMA:
• Registra en PostgreSQL
• Estado: "Pendiente"
• Timestamp automático

FASE 2: ASIGNACIÓN ⚙️

ADMINISTRADOR:
• Revisa solicitudes pendientes
• Consulta disponibilidad de mecánicos
• Evalúa especialidades técnicas
• Asigna mecánico óptimo

SISTEMA:
• Actualiza estado laboral → "Ocupado"
• Vincula mecanicoId a solicitud
• Envía notificación al mecánico

FASE 3: EJECUCIÓN DEL SERVICIO 🔧

MECÁNICO:
• Recibe vehículo en fecha programada
• Actualiza estado → "En Proceso"
• Realiza diagnóstico completo
• Ejecuta trabajos autorizados
• Registra en sistema:
  ✓ Diagnóstico realizado
  ✓ Trabajos ejecutados
  ✓ Repuestos utilizados
  ✓ Costos (mano obra + repuestos)
  ✓ Observaciones técnicas

ELEMENTOS VISUALES:
- Diagrama de flujo simplificado con 3 fases
- Iconos: smartphone, admin, mecánico
- Colores por estado (Pendiente=azul, Proceso=amarillo)
